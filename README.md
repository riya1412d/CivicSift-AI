# CivicSift AI

### An Evidence-Aware Multilingual NLP Framework for Citizen Complaint Analysis

## Project Overview
CivicSift AI is a proposed Natural Language Processing (NLP) framework designed to analyse citizen complaints written in multiple languages, including English, Hindi, Kannada, and Romanised or code-mixed text.

The system aims to classify complaints, estimate urgency, identify similar or duplicate complaints, and support better complaint management.

## Problem Statement
Citizen complaints are often received in different languages and writing styles. Manually analysing and categorising them can be time-consuming and may lead to delays or duplicate records.

CivicSift AI aims to address these challenges using NLP and machine learning techniques.

## Objectives
- Classify citizen complaints into relevant categories.
- Estimate complaint urgency using textual evidence.
- Identify similar and duplicate complaints.
- Support multilingual and code-mixed text.
- Provide useful insights through a simple dashboard.

## Key Features
- Multilingual complaint classification.
- Evidence-aware urgency estimation.
- Duplicate complaint detection.
- Important information extraction.
- Human-reviewed complaint management.

## Proposed Technologies
- Python
- Natural Language Processing
- Scikit-learn
- TF-IDF
- Logistic Regression
- IndicBERT / XLM-R
- Sentence Transformers
- Streamlit

## Proposed Methodology
1. Collect suitable public or synthetic complaint data.
2. Clean and preprocess the text.
3. Extract relevant textual features.
4. Train and evaluate complaint classification models.
5. Estimate urgency using textual indicators.
6. Identify similar complaints using semantic similarity.
7. Develop a simple dashboard for displaying results.
