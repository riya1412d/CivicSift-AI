
# Week 6 – CivicSift AI Final Project Report

## Project Overview
CivicSift AI is an NLP-based citizen complaint analytics project using NYC 311 complaint data.

## Project Coverage
This final report consolidates the work completed across the six internship weeks:

1. NLP Project Planning and Proposal
2. Data Collection, Preprocessing and Feature Engineering
3. Text Classification and Model Evaluation
4. Named Entity Recognition Pipeline Design
5. Topic Modeling and Extractive Text Summarization
6. Final Project Report and Documentation

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- TF-IDF
- Logistic Regression
- Multinomial Naive Bayes
- Linear SVM
- Latent Dirichlet Allocation (LDA)
- NLP preprocessing and text summarization

## Important Note
The final report distinguishes between implemented experiments, proposed methodologies and pipeline designs. Results and limitations are documented according to the work completed in each week.
