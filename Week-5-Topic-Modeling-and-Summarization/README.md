# Week 5 – Topic Modeling and Extractive Text Summarization

This project implements an NLP pipeline using NYC 311 complaints.

## Tasks
1. Text Preprocessing
2. LDA Topic Modeling
3. TF-IDF Based Extractive Summarization
4. Model Evaluation

## Technologies
- Python
- Pandas
- Scikit-learn
- NumPy
- LDA
- TF-IDF

See the project report for methodology, results and evaluation.
