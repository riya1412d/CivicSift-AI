# Week 3 – Text Classification

This folder contains the implementation and evaluation of NLP text classification models for CivicSift AI.

## Models Implemented
- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Machine (SVM)

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF

The project includes data preparation, model training, evaluation, prediction and performance comparison.
